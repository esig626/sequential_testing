# Research sources

This directory is the repository's persistent source library. It exists so future research does not waste time or tokens rediscovering literature that has already been found, read, and classified.

Before any external literature search, first inspect:

1. `docs/RESEARCH_LEDGER.md` for overlapping result, failure, method, boundary, and open-problem IDs;
2. this directory and its topic folders;
3. `references.bib` and any topic-specific `references.bib`;
4. relevant `SOURCE.md` records;
5. literature-audit notes cited by the ledger;
6. repository search results for the relevant author, theorem, concept, formula, and keywords.

If an existing source already answers the research question, use that source rather than repeating the search. Search externally only for a clearly identified gap, verification/update need, explicit fresh-search request, or genuinely new extension. New useful sources must be recorded here before the research task is complete.
